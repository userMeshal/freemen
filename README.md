# Freemen V3 | فريمان

نسخة أكثر احترافية من منصة فريمان، فيها لوحة تاجر موسعة تشبه منصات المتاجر الكبيرة من ناحية الوظائف، لكن بهوية أصلية.

## صفحات مهمة

- `/dashboard` الرئيسية
- `/products` المنتجات
- `/orders` الطلبات
- `/customers` العملاء
- `/coupons` الكوبونات
- `/shipping` الشحن
- `/payments` المدفوعات
- `/wallet` المحفظة والتحويلات
- `/design` تصميم المتجر
- `/pages` الصفحات والسياسات
- `/analytics` التقارير
- `/apps` التطبيقات
- `/admin` إدارة المنصة
- `/store/swan` متجر تجريبي

## ملاحظة

هذه نسخة واجهات بدون قاعدة بيانات. الخطوة القادمة ربط Supabase.
