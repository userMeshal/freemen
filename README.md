# Freeman MVP | فريمان

منصة متاجر إلكترونية أولية باسم **فريمان**.

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح:

```text
http://localhost:3000
```

## الصفحات الموجودة

- `/` الصفحة الرئيسية
- `/register` تسجيل تاجر
- `/login` تسجيل دخول
- `/create-store` إنشاء متجر
- `/dashboard` لوحة التاجر
- `/products` إدارة المنتجات
- `/orders` الطلبات
- `/settings` إعدادات المتجر
- `/admin` لوحة إدارة المنصة
- `/pricing` الباقات
- `/store/swan` متجر تجريبي

## ملاحظات

هذه نسخة واجهات MVP بدون قاعدة بيانات حقيقية.  
الخطوة التالية: ربط Supabase وحفظ التسجيل والمنتجات والطلبات فعليًا.
