# بدلني — سوق المقايضة السعودي

موقع مقايضة بدون مال: تعرض غرضك، تحدد وش تبي بداله (أو تستقبل كل العروض)، يوصلك عروض بدل، تقبل اللي يعجبك وتتبادلون.

## الصفحات
- `/` الرئيسية — مشهد البدل المتحرك، كيف يشتغل، العروض، المميزات
- `/browse` تصفّح العروض — بحث، أقسام، مدن
- `/listing/[id]` صفحة العرض — التفاصيل، «اعرض بدلك»، ميزان البدل
- `/new` أضف عرض — ثلاث خطوات مع رفع صور
- `/offers` عروضي — وصلتني / أرسلتها / المفضلة

## التشغيل
```bash
npm install
npm run dev      # http://localhost:3000
```

## النشر
اربط المستودع بـ Vercel واضغط Deploy — ما يحتاج أي إعدادات.

## قاعدة البيانات وتسجيل الدخول (Supabase)
الموقع له وضعين:
- **تجريبي** (الافتراضي): بدون إعداد، البيانات في متصفح الزائر مع عروض نموذجية.
- **حقيقي**: أول ما تنضبط قيم Supabase — حسابات بإيميل وكلمة مرور، عروض يشوفها الكل، صور مرفوعة، وعروض بدل توصل لحظياً.

### التفعيل
1. أنشئ مشروع في [supabase.com](https://supabase.com).
2. **SQL Editor** ← الصق محتوى `supabase/schema.sql` كامل ← **Run**.
3. **Authentication ← Sign In / Providers ← Email** ← اطفئ **Confirm email** (إيميلات Supabase المجانية محدودة جداً بالساعة).
4. من زر **Connect** انسخ `Project URL` والمفتاح العلني (`publishable` أو `anon`). لا تستخدم `service_role` أبداً.
5. حط القيمتين في `.env.production` باسم `NEXT_PUBLIC_SUPABASE_URL` و `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` (علنيتين، وهي مضبوطة حالياً على مشروع «بدلني»)، أو أضفهم في Vercel ← **Environment Variables**.

للتشغيل المحلي: انسخ `.env.example` إلى `.env.local` وعبّ القيم.

### استرجاع كلمة المرور
من صفحة الدخول ← «نسيت كلمة المرور؟» ينرسل رابط على الإيميل يفتح `/reset`. عشان الرابط يرجّع المستخدم للموقع الصحيح، اضبط في Supabase ← **Authentication ← URL Configuration**:
- **Site URL**: رابط الموقع (مثل `https://suysaudi.co`).
- **Redirect URLs**: أضف `https://suysaudi.co/**` وأي رابط ثاني للموقع (مثل رابط Vercel).

إيميلات Supabase المجانية محدودة بعدد قليل بالساعة؛ للاستخدام الفعلي اربط مزوّد بريد (SMTP) من **Authentication ← Emails ← SMTP Settings**.

### الأمان
كل القواعد في القاعدة نفسها (RLS) داخل `supabase/schema.sql`:
- العروض يقرأها الكل، وما يعدّلها أو يحذفها إلا صاحبها.
- عرض البدل يشوفه مرسله وصاحب الغرض فقط، والقبول/الرفض لصاحب الغرض فقط.
- رقم الواتساب في جدول مستقل ما ينقرأ إلا بين طرفين بينهم عرض مقبول.
- كل مستخدم يرفع الصور داخل مجلده فقط.

### غير موجود للحين
تعديل العرض بعد نشره، والتبليغ عن عرض مخالف.

## الشعار
ملفات الشعار في `public/brand/` (وتنفتح من الموقع على `/brand/اسم-الملف`):

| الملف | الاستخدام |
| :--- | :--- |
| `badalni-logo` | الشعار الكامل (الرمز + الاسم) على خلفية فاتحة |
| `badalni-logo-white` | الشعار الكامل على خلفية داكنة |
| `badalni-icon` / `badalni-icon-white` | أيقونة مربعة — حسابات التواصل وأيقونة التطبيق |
| `badalni-symbol` / `badalni-symbol-white` | الرمز لوحده بخلفية شفافة |
| `badalni-wordmark` / `badalni-wordmark-white` | الاسم لوحده |

كل ملف موجود بصيغة SVG (يتكبّر بدون ما يخرب — للطباعة والتصميم)، والأساسية منها PNG بخلفية شفافة.
الاسم محوّل لمسارات فما يحتاج تثبيت خط. اللون الأسود `#0D0D0D` والأبيض `#FFFFFF`.
