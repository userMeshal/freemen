# بدل — سوق المقايضة السعودي

موقع مقايضة بدون مال: تعرض غرضك، تحدد وش تبي بداله (أو تستقبل كل العروض)، يوصلك عروض بدل، تقبل اللي يعجبك وتتبادلون.

## الصفحات
- `/` الرئيسية — مشهد البدل المتحرك، كيف يشتغل، العروض، المميزات
- `/browse` تصفّح العروض — بحث، أقسام، مدن
- `/listing/[id]` صفحة العرض — التفاصيل، «اعرض بدلك»، ميزان البدل
- `/new` أضف عرض — ثلاث خطوات مع رفع صور
- `/offers` عروضي — وصلتني / أرسلتها / المفضلة

## التشغيل
```bash
npm install
npm run dev      # http://localhost:3000
```

## النشر
اربط المستودع بـ Vercel واضغط Deploy — ما يحتاج أي إعدادات.

## مهم
هذه نسخة تجريبية كاملة الواجهات: البيانات (عروضك، عروض البدل، المفضلة) تنحفظ في متصفح الزائر فقط (`localStorage`)،
والعروض النموذجية والردود المعلّمة بـ«تجريبي» موجودة لتوضيح التجربة. عشان يشوف المستخدمون عروض بعض فعلياً
لازم ربط قاعدة بيانات وتسجيل دخول (مثل Supabase) — كل منطق البيانات في `lib/store.tsx` لتسهيل الاستبدال.
