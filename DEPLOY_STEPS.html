طريقة نشر منصة فريمان

هذه الخطوات للمبتدئ من الصفر. تحتاج ماك بوك، حساب GitHub، وحساب Vercel.

1) فك الضغط

فك ملف freeman-deploy-ready.zip على سطح المكتب.

2) افتح GitHub

سجل دخولك في GitHub، ثم اضغط New Repository.

اسم المستودع: freeman

خله Public أو Private عادي.

3) ارفع ملفات المشروع

ادخل المستودع الجديد، اضغط uploading an existing file.

اسحب كل الملفات اللي داخل مجلد المشروع، مو ملف ZIP نفسه.

لازم تشوف ملف package.json ظاهر في الصفحة الرئيسية للمستودع.

4) افتح Vercel

سجل دخولك في Vercel بنفس حساب GitHub.

اضغط Add New ثم Project.

اختر مشروع freeman من GitHub.

5) إعدادات النشر

Vercel غالبًا يتعرف عليه تلقائيًا كـ Next.js.

خلي الإعدادات كذا:

Framework: Next.js

Build Command: npm run build

Install Command: npm install

Output Directory: اتركه فاضي

6) اضغط Deploy

بعدها انتظر لين يطلع لك رابط مثل:

https://freeman.vercel.app

كذا صار عندك رابط حقيقي.

إذا طلع خطأ

أرسل صورة الخطأ، وأهم شيء تأكد إن ملف package.json موجود في الصفحة الرئيسية للمستودع في GitHub.
